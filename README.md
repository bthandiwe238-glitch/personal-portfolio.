Create a **bold, vibrant, futuristic and highly professional cybersecurity portfolio website** for **Ayanda Thandiwe Buthelezi**, an aspiring cybersecurity professional from South Africa.

## 🎨 VIBRANT COLOUR DIRECTION

Use a rich dark foundation but make the colours **bright and visually dominant**.

Primary palette:

* **Electric Cyan** — `#00F5D4`
* **Neon Purple** — `#8B5CF6`
* **Vivid Violet** — `#A855F7`
* **Electric Blue** — `#2563FF`
* **Hot Magenta** — `#EC4899`
* **Bright Orange** — `#FF7A18`
* **Lime Green** — `#A3FF12`
* **Deep Navy** — `#07152B`
* **Dark Purple** — `#160B2E`
* **White** — `#F8FAFC`

Use **cyan, purple, blue, magenta and orange gradients throughout the website**.

Examples:

* Cyan → blue
* Purple → magenta
* Blue → violet
* Orange → pink
* Cyan → lime

Use vibrant gradient borders, glowing buttons, colourful cards, gradient text and neon highlights.

### Important

The website should **not** be mostly dark navy.

The dark background should provide contrast, while the vibrant colours should be clearly visible throughout the design.

Use colourful gradients behind sections, glowing shapes, neon lines, gradient cards and colourful icons.
